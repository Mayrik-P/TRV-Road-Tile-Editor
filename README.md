# TRV Road Tile Editor

A free, fan-made web app to design your own road tiles for the board games
**Thunder Road: Vendetta** and **Ignition** (Restoration Games), then print them at true game size.

👉 **Use it here: https://mayrik-p.github.io/TRV-Road-Tile-Editor/**

No installation, no account: it runs in any modern browser, on a computer, tablet or phone.

## Features

- Paint the spaces of a Vendetta (8 spaces wide) or Ignition (4 spaces wide) board, with a brush
- Free decorations (cacti, snakes, road signs…) placed where you want
- Undo / Redo, keyboard shortcuts (press **?** in the editor)
- Automatic saving in your browser, and project files to reopen a board anywhere
- Export as PNG or PDF at 300 dpi, on A3 / A4 or US Tabloid / Letter paper, with a ruler to check the print scale
- Custom title image and road name

## Running it locally

The app is plain HTML, CSS and JavaScript, with no build step. Serve the repository folder with any
static web server, for example:

```bash
python3 -m http.server 8765
```

then open http://localhost:8765/index.html.
