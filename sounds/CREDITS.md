# Sounds

Short interface sounds reused from TRV-Pocket (same author). All come from
[freesound.org](https://freesound.org) and are released under the
**Creative Commons 0** license (public domain): no attribution required.

Prepared from the TRV-Pocket OGG files: trailing silence trimmed, converted to
MP3 128 kbit/s (read by every browser, including older Safari versions).

| File | Moment in the editor |
|---|---|
| `dash-zoom.mp3` | pick a space type in the palette |
| `card-flip.mp3` | place a space (click, brush, keyboard) |
| `tap-back.mp3` | undo / redo |
| `stamp.mp3` | clear board |
| `finish-flag.mp3` | export finished (PNG or PDF) |
| `tap-refuse.mp3` | file or image refused, export error |
| `tap-menu-button.mp3` | other buttons |
